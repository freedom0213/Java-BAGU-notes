## 怎么写

**就在记事本里改 `C:\Users\freedom\Desktop\java八股2.txt`**，沿用你原来的书写习惯，不需要学任何新格式。

同步时脚本会自动解析：

| txt 里这么写 | 页面上变成 |
| :--- | :--- |
| `==================== 一、Spring（45 题）====================` | 新的一章（出现在左侧目录） |
| `（一）索引` | 小节标题 |
| `16：题目？` | 一道题，显示为绿色标记条 |
| 缩进的正文 | 答案，一行一个要点（自动处理换行，**不用管行尾空格**） |

改完双击 `同步到GitHub.bat`，约 30 秒后线上生效。

### 如果换了电脑、或把 txt 改名/挪了位置

只需修改 `tools/sync.py` 顶部的 `NOTE_TXT` 常量，填新路径即可。
